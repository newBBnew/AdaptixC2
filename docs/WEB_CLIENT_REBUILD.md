# AdaptixC2 Web Client 改造计划备忘 (2026-01-01)

## 1. 核心目标
将传统的 Qt 桌面客户端逐步迁移至现代化的 Web 架构，实现全平台访问、增强的战术协作能力以及深度的 MSF 集成。

## 2. 核心板块设计
- **Dashboard (仪表盘)**：系统全局概览，实时统计 Agent 活跃度、攻击任务进度、系统资源状态。
- **Agents (控守平台)**：核心板块。复刻并超越 Qt 端的会话管理，支持 Agent 列表展示、交互式控制台、文件浏览、进程管理。
- **Tactical (战术中心)**：
    - **MSF 联动**：深度集成 Metasploit RPC，图形化展示模块库。
    - **战术图谱**：以交互式决策树/流程图形式展示攻击路径，支持拖拽式命令下发。
- **Settings (设置)**：MCP 服务配置、UI 主题、字体偏好、认证管理。

## 3. 技术约束与规范
- **前端栈**：React + Vite + TailwindCSS + Lucide Icons + Framer Motion (交互动画)。
- **Server 侧变动约束**：
    - **原则**：尽量不修改 `AdaptixServer` 现有逻辑，优先复用现有 API。
    - **例外**：若必须修改（如新增特定同步包、MSF 桥接接口），**必须先获得用户明确授权**。
- **SOCKS 方案**：采用 `Adaptix-Bridge` 模式解决浏览器沙箱无法本地监听的问题。

## 4. 阶段规划
1. **骨架搭建**：侧边栏导航、多标签页容器、主题基础。
2. **数据同步**：对接 WebSocket / SyncPacket，实现 Agent 状态实时更新。
3. **功能复刻**：按优先级迁移控守平台的核心交互功能。
4. **战术增强**：上线战术中心与 MSF 模块。
